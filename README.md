# Multicountry Heatwave and Mental Health Hospitalization

Code for analyzing associations between heatwaves and mental health hospitalizations across multiple countries.

## About

This repository contains analytical code to support an academic paper on heatwaves and mental health hospitalization.

## Workflow

Run the notebooks in this order:

1. `step1_dataprep.ipynb` — data preparation
2. `step2_rr_estimate.ipynb` — risk estimation
3. `step3_figureandtable_preparation.ipynb` — figure and table preparation
